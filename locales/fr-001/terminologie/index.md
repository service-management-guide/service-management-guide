# Terminologie pour le français

Les traducteurs suivent ces choix. Les noms propres (ITIL, Scrum, Kanban, DevOps, DORA, SRE, AIOps, FinOps et les noms d'outils et de produits) restent inchangés. Là où il n'existe pas de terme français établi, le terme anglais figure entre parenthèses à la première occurrence dans chaque sujet. Les liens vers Wikipedia en anglais, les titres des références et les noms des fichiers de compétences restent en anglais. Adresse : vouvoiement. Monnaie des exemples : dollar américain (USD) ; date AAAA-MM-JJ ; unités métriques ; virgule décimale ; espace insécable avant les deux-points, le point-virgule, le point d'interrogation et le point d'exclamation. Format des renvois : « Sujet N.N — Titre ». Pour ITIL 5, seul ce qui est étayé par les publications de son propriétaire (PeopleCert) est utilisé ; tout le reste demeure signalé comme non confirmé. Les blocs d'invites d'IA restent en anglais.
