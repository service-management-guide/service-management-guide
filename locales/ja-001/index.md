# サービスマネジメントガイド

**アジャイル、AI、自動化、アナリティクスで行うサービスマネジメント。**

サービスマネジメントとは、組織が顧客と共に価値を創造する方法です。ITIL 5はそれをデジタルプロダクト、AI、測定可能な価値を軸に捉え直します。このガイドは、アジャイル、AI、自動化、アナリティクスという四つのレンズを通して運用する方法を、調査、プラクティス、事例、チームで話し合うためのアイデア、AIスキル、AIプロンプトとともに示します。
